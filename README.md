# OOPLab2 — Satellite Management System

Консольна програма на C# для управління колекцією штучних супутників з інкапсульованими властивостями

## Опис

Програма реалізує клас `Satellite` з характеристиками (назва, тип, висота
орбіти, дата запуску, потужність передавача, стан активності, рівень
пального, категорія орбіти) та поведінкою (передача даних, перемикання
живлення, зміна висоти орбіти, симуляція природного зниження орбіти)

Порівняно з Lab-1, усі характеристики класу закриті (`private`) і доступні
лише через публічні властивості з валідацією значень усередині. Додано
автовластивість зі значенням за замовчуванням, обчислювану властивість та
властивості з різним рівнем доступу для читання й запису

## Функціонал

- Додавання об'єкта (вручну / за замовчуванням) з обмеженням кількості N
- Перегляд усіх об'єктів у табличній формі
- Пошук за типом або назвою
- Демонстрація поведінки об'єкта
- Видалення за номером або за типом

## Структура проєкту

- `Program.cs` — точка входу, меню, введення й обробка виключень при
  встановленні значень властивостей
- `Satellite.cs` — клас супутника з властивостями та приватними методами
- `SType.cs` — enum типів супутників

## Запуск

```
dotnet run
```
